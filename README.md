# Описание проекта
Приложение представляет собой веб‑планировщик задач со следующими возможностями:
    1. веб‑интерфейс;
    2. добавление новых задач с возможностью переодического повторения;
    3. просмотр списка всех задач;
    4. взаимодействие с задачами (удаление, отметка о выполнении, редактирование);
    5. поддержка аутентификации через JWT‑токены;
    6. хранение данных в БД.

# Инструкция по запуску кода локально
    1.Клонируйте репозиторий:
        git clone <url-репозитория>
        cd go_main_final_project
    2. Установите зависимости:
        go mod tidy
    3. Запустите сервер:
        (Без аутентификации)
        go run main.go
        (С аутентификацией)
        TODO_PASSWORD="test123" go run main.go
    4. Откройте в браузере:
        http://localhost:7540
    5. Для доступа к странице авторизации перейдите по адресу:
        http://localhost:7540/login.html

# Запуск тестов
Все тесты
go test ./tests

Конкретный тест
go test -run ^TestAddTask$ ./tests

# Запуск контейнера
docker run -d \
  --name todo-app \
  -p 7540:7540 \
  -v $(pwd)/data:/app/data \
  -e TODO_PASSWORD="test123" \
  -e TADO_DBFILE="/app/data/custom.db" \
  todo-sheduler

# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

В директории `pkg` находится логика приложения, разделённая по пакетам. `api` - обработчик всех api, `auth` - для аутентификации пользователя, `config` - для хранения и обработки конфигурации приложения, `db` - для подключения и взаимодействия с БД, `handlers` - обработка HTTP‑запросов, `models` - для описание структуры модели  `repeat` - для повторения задач, `validation` - для проверки данных на корректность.

В дирректории `server` указаны параметры подключения к серверу.
